Read before filing a defect 4 already confirmed on v0.1.4 ▸

These four were found and confirmed while writing this playbook. They reproduce on v0.1.4 — do not open duplicates:

  • ZADD k 1 a 2 b 3 c returns 1 and stores only a. Surplus score/member pairs are silently dropped (CORE-28).
  • LPOP, RPOP, SPOP, SRANDMEMBER accept a count argument and ignore it (CORE-19, CORE-23b).
  • INCR on a non-numeric value and RENAME on a missing key reply without the ERR prefix (CORE-06, CORE-32).
  • SET k v NX XX and SET k v EX 100 PX 5000 are accepted instead of rejected as a syntax error (CORE-03).

Intentional divergences from real Redis — partial KEYS globs, 4-field SLOWLOG, full-resync-only replication and more — are listed under “Known limits” in docs/qa-playbook.md. Check there before reporting anything.

Before you run anything

export ROCKET_MEM_REPO=/path/to/your/rocket-mem
export ROCKET_MEM_BIN="$ROCKET_MEM_REPO/target/release/rocket-mem"

Every case reads those two. The Environment setup suite covers all three ways to get a running server — build from source, run the Docker image, or download a release.
